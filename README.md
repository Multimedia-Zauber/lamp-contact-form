# Lamp Contact Form 💡

An interactive contact form with a pull-cord lamp animation.

The page starts in a dark state with only the lamp visible.  
When the user pulls the cord, the lamp turns on, the light cone appears and the contact form fades into view.

## Features

- Interactive pull-cord lamp
- Light on/off animation
- Animated light cone
- Contact form reveal animation
- Responsive design
- Pure HTML, CSS and JavaScript
- No framework required

## Technologies

- HTML5
- CSS3
- JavaScript

## Files

- `index.html`
- `style.css`
- `script.js`

## Usage

1. Clone or download the repository.
2. Open `index.html` in your browser.
3. Pull the lamp cord.
4. The contact form appears.

## Preview

💡 Pull the cord → Light turns on → Contact form appears

## Note

The form currently uses a demo submit animation and does not send real emails.
